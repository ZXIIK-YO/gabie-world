# Gabie World

PWA mobile-first para planejar, comprar, acompanhar e montar computadores.

`npm run dev` inicia o projeto. O modo convidado funciona sem variáveis e persiste no navegador. Para sincronização, aplique `supabase/migrations/0001_initial.sql` e configure `.env.example`. A busca manual usa a API pública do Mercado Livre; o classificador Cloudflare é ativado quando suas variáveis existem.
